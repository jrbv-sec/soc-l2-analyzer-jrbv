# soc-l2-analyzer-jrbv
**Proyecto final SOC L2 Analyzer**
Plataforma de Triage y Respuesta a Incidentes SOC Nivel 2 con IA.

**Enlace a la App**
URL: https://soc-l2-analyzer-jrbv-xsy4ezdffpb92dkeqs4hwe.streamlit.app/

**Objetivo**
Aplicación diseñada con el objetivo de correlacionar eventos TTPs de MITRE ATT&CK / D3FEND, permitiendo realizar el análisis, revisión de eventos de manera estructurada, así como la generación de informe técnico.

**Estructura de las 6 funcionalidades** 

**01 - Carga de archivos:** Importar y visualizar el archivo de logs.
**02 - Análisis de seguridad:** Identificar eventos sospechosos y correlacionarlos.
**03 - Dashboard:** Estadísticas y gráficos interactivos por criticidad.
**04 - Clasificación de Riesgos:** Crítico, Alto, Medio, Bajo (Con justificación).
**05 - Informe técnico:** Estructurado y completo.
**06- Exportación:** Informe en formato PDF descargable.
